# Versões de teste

Sempre que uma nova compilação estiver pronta para teste, atualize a instalação local do ServiceDesk usada para validação e confirme que o aplicativo abre. Preserve as configurações do usuário e a numeração oficial durante esse ciclo.

Abra a PR de atualização da versão somente após a conclusão dos testes, das alterações e da validação pelo usuário.
